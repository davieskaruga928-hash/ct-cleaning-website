# CT Cleaning Service — Website

A website built for CT Cleaning Service, a Nairobi-based cleaning company serving homes, offices, churches/events, and large institutions (e.g. Northlands), to generate more client leads and present a more credible, institutional-grade brand.

## Status

**Phase 1 (in progress):** static marketing site
- [x] Homepage
- [ ] Services page
- [ ] About page
- [ ] Gallery page
- [ ] Contact / Quote request page (frontend only)

**Phase 2 (planned):** FastAPI + PostgreSQL backend
- [ ] Quote request form wired to a database
- [ ] Admin dashboard for managing leads
- [ ] Auto-generated PDF quotations

## Tech stack

- HTML / CSS (vanilla) for the static site
- FastAPI + PostgreSQL for the backend (phase 2)
- Fonts: Archivo (headings), Inter (body)

## Project structure

```
ct-cleaning-website/
├── index.html
├── css/
│   └── style.css
└── assets/
```

## Running locally

Just open `index.html` in a browser — no build step for the static phase.
